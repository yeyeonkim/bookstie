# Bookstie (북스티)

Java Swing 기반 도서 대출 및 독서 기록 관리 프로그램
데이터베이스 없이 로컬 txt 파일에 데이터를 저장하는 방식으로 구현함.

## 주요 기능

- 회원가입 및 사용자·관리자 로그인
- 도서 검색 및 대출
- 대출·연체 현황 조회
- 내 서재 및 별점 등록을 통한 완독 표시
- 관리자 도서 등록·삭제, 회원 조회·삭제, 반납 처리

대출 기간은 14일이며, 반납은 관리자 페이지에서 관리자가 처리한다.
별점 등록에 따른 완독 처리와 실제 반납 처리는 독립적으로 이루어진다.

## 실행 방법

Java 25 이상이 설치된 환경에서 실행.
**JAR 파일과 data 폴더를 같은 폴더에 둔 뒤, 해당 폴더에서 다음 명령을 실행한다.**

```bash
java -jar ssd_ip_cp4_2026f_234019_app.jar
```

data 폴더에는 users.txt, admins.txt, books.txt, loans.txt가 포함되어야함.
폰트와 아이콘은 JAR 내부에 포함되어 있음.

## 테스트 계정

| 구분 | 아이디 | 비밀번호 |
|---|---|---|
| 일반 사용자 | jjjj | jjjj |
| 관리자 | admin | 1234 |

**관리자 로그인 화면은 사용자 로그인 화면의 admin 버튼으로 이동할 수 있음.**


API 문서는 docs/api/index.html에서 확인 가능함.
